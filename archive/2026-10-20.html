4. Google Open-Sources Harness2, a Recursive Agent Harnessing Framework

Google has released Harness2, a new open-source framework (a set of shared tools and code) for building AI agents. An agent is a program that can plan steps and use tools to complete tasks on its own. The framework uses a recursive approach, meaning it can call itself repeatedly to improve its results.

In tests, Harness2 raised the score of a model called GLM-5 by 11.5 points on WorkBuddy-Bench, a benchmark (a standard test) for work tasks. The model's internal settings, or weights, stayed frozen, so the gain came from better organization rather than extra training. Developers can now study and modify the code for their own projects.

💡 What this means for you: Open-source tools like Harness2 let smaller companies and independent developers build advanced AI without huge budgets. This can speed up innovation and lower costs, but it also raises questions about safety and control. For workers, better AI agents may change how everyday office tasks are done.
